# SWOT Analysis Web App

A web application that uses LLMs (via OpenAI) to generate SWOT (Strengths, Weaknesses, Opportunities, Threats) insights for different customer segments. The user provides a product and a target audience (segment), and the app generates strategic insights based on that input. Generated reports can be viewed, compared, and saved for later reference.

## ✨ Features

- 🔍 Generate SWOT analysis using OpenAI's LLM
- 📦 Input includes product and customer segment
- 🧠 Automatically creates structured insights (Strengths, Weaknesses, Opportunities, Threats)
- 💾 Save generated reports
